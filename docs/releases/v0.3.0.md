# XC for Silo 0.3.0

- Relay embedded live MPEG-TS and HLS without sending provider credentials to the browser.
- Add shared GPU compatible playback, optional Live Rewind, and explicit station priorities with startup account/source fallback.
- Adopt each watch reservation once, enforce viewer ownership, and preserve provider connection limits.
- Reuse indexed Sports guide data and background preparation to keep requests within the route deadline.
- Update to Silo Plugin SDK v0.30.0.

Validation: repository release checks, shared race and browser lifecycle tests, local emulator playback checks, and MPEG-2/AC-3 to H.264/AAC conversion on the Silo server GPU. Physical HDHomeRun hardware was not available; device tests use local emulators and Dispatcharr.
