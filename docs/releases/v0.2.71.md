# v0.2.71

My TV brings favorite channels and saved guide searches together, with team and league follows when Sports is enabled. Search adds ranked matches and channel hearts while retaining Xtream movies and series.

The guide adds program search, a Now button, and keyboard navigation while retaining bounded rendering and provider EPG warm-up. Player controls use the updated icons, playback state, overflow clipping, and More menu; REPLAY channels retain native seeking controls.

Sports is disabled by default. Enable it in XC Admin → Settings → Sports and save. The setting persists across restarts. Sports provides live scores, channel matches, league/team follows, and player access through More → Sports center.

The Replays tab lists only channels whose provider name or category contains REPLAY or REPLAYS. It respects source/profile selection and hidden categories. It never searches Silo libraries. DVR and recording routes remain unavailable.

Validation: release verification script (vet, full Go tests, race tests, JavaScript syntax, generated manifest); feature behavior regression tests; 16 mocked browser interaction checks; visual checks of My TV, guide, Sports, and Replay rows. Provider playback continues through the existing Xtream account pool and relay.
