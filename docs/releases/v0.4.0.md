# XC for Silo 0.4.0

- Fill missing guide coverage with attributed pregame, game, and postgame listings from the existing Sportarr/ESPN schedule pipeline.
- Keep provider EPG unchanged and clip generated entries around it. Mark all generated coverage windows as estimates with provider, event, phase, and match evidence.
- Add Sports guide admin controls for per-group league hints, matchup or tournament/session matching, manual event links, and disabling automatic filling for a group/channel.
- Cache generated listings in a separate private SQLite overlay that survives restarts and schedule-provider outages. Source/policy changes, renamed channels, and stale entries invalidate old results.
- Keep schedule fetches and generation in background jobs. Generated entries never feed back into sports matching as independent EPG evidence.

Automatic matching requires both competitors and league context, or a complete normalized session title. Ambiguous fixtures and canceled/postponed events are left unmatched. Manual event links apply only to the chosen event and never roll to another fixture. Existing provider connections, channel names, recording modes, and playback behavior are preserved.
