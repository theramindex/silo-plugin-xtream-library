# XC for Silo 0.3.3

- Store EPG schedules in private local SQLite databases and query only the requested channel/time window.
- Load catalog metadata at startup without decoding the entire schedule. Import existing JSON caches in the background; keep the original files for rollback.
- Commit guide rows and metadata together, preserve the last good guide on refresh failure, and keep reads available during imports.
- Each account has its own private database. Sports preparation reads the persisted guide in background jobs.

The database uses WAL mode and requires local storage. Legacy JSON files are no longer updated after migration. Full-guide exports remain available; SQLite read failures return a temporary error instead of an empty successful guide. No change to Silo's server database is required.
