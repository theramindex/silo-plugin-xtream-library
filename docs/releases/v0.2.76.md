# v0.2.76

Jellyfin Live TV through the theramindex Silo fork:

- Connection limits: a Jellyfin play leases a playback account from the same pool the web app uses, so it counts against each account's stream limit. When every account is in use, Silo tells the client the stream is rate limited instead of overloading the provider. The `livetv/v1` `stream` route takes a `session_id`, and new `session/heartbeat` and `session/stop` routes renew and free the lease.
- Per-user folders: the `channels` route adds `pipeFolders`, the folders a user who groups categories by `|` sees, so Silo can show each user their own layout. The admin's layout stays the default.
- Program rows: Jellyfin's Sports and other rows list real games first. Placeholders titled with their own channel's name, previews of later games, radio feeds and titles many channels repeat come last. Filler such as "Signing Off" and paid programming are in no row.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests, race tests), plus the JavaScript regression tests.
