# v0.2.74

Jellyfin guide: the plugin serves the `livetv/v1` `programs` route, which the theramindex Silo fork uses for the Jellyfin guide grid, the Programs tab rows (On Now, Shows, Movies, Sports, Kids, News) and each channel's current program. Programs are classified from their guide categories, falling back to the channel's group and name; filler such as "NO EVENT" stays in the grid but in no row. With the sports feature on, programs matched to a game in the sports guide take the game's name and artwork and are marked `featured`, so they lead Jellyfin's rows.

Xtream guides load per channel, so when Silo asks for channels that have no guide yet, the plugin loads up to 100 of them in the background, 8 at a time, with a 30-minute cooldown per channel. The next guide request shows them.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests, race tests), plus the JavaScript regression tests.
