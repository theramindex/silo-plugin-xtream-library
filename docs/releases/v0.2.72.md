# v0.2.72

Security and playback: HLS relay fetches are limited to configured provider hosts and the stream origin. Credentialed HLS is relayed on every route, and more credential forms are detected. A new XC Admin setting, "Allow direct provider URLs", is on by default; when it is off, credentialed non-HLS streams return `stream_requires_hls` instead of redirecting to the provider. Forced guide refresh is now admin-only, and connection-test errors for alternate EPG sources no longer include credentials.

The guide is indexed per snapshot and loads in time windows (`start`, `end`, `channel_ids`). XMLTV, including gzip, is parsed as a stream under the size cap. A refresh that loses more than half of the guide keeps the last good guide instead.

Sports admits tennis and golf majors such as the US Open from one-sided listings, and nameless teams no longer share a phantom ID. Fetching, matching, and enrichment each have their own deadline, and partial results are never cached. League data lives in one registry.

The UI never writes plugin settings after a failed read, and it queues, debounces, and merges saves. Sports preference keys are kept, preferences sync across tabs, and phantom team follows are purged. Superseded watch sessions stop, including multiview tiles. Inline handlers are replaced and a Content-Security-Policy is added. Refresh controls are hidden from non-admins.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests), plus the JavaScript regression tests for review fixes, preference sync, and watch sessions.
