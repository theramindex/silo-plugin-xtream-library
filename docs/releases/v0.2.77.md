# v0.2.77

Per-user providers (off by default):

- XC Admin → Organization → **Users add their own providers** lets each Silo user add their own Xtream Codes server and credentials under Settings → My providers, with their own channels, guide, and refreshes. Users without a provider see nothing; shared sources are not used while it is on.
- Credentials stay private: XC Admin never opens a user's providers, passwords are never returned after saving, and each user's registry is stored AES-256-GCM sealed under the plugin state directory.
- Every request for a user's provider refuses loopback, private, and link-local addresses, so users cannot reach the server's network through XC.
- `livetv/v1` `info` reports `perUserLineup`, so the theramindex Silo fork's Jellyfin bridge keeps lineups, guides, and stream hosts per user.

Web app: `app.js` is split into core, prefs, sports, admin, multiview, guide, player, and app parts, served as one composed script as in Dispatcharr. `features.css` is merged into `styles.css`. No behavior change.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests, race tests, every UI script syntax-checked), plus the JavaScript regression tests.
