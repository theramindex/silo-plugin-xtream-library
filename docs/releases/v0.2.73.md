# v0.2.73

Live TV for Jellyfin clients: the plugin implements the `livetv/v1` contract (`/silo-compat/livetv/v1/info`, `channels`, `stream`), which the theramindex Silo fork uses to show Xtream channels in Jellyfin apps. `info` and `stream` are admin-only because stream URLs carry provider credentials; Silo calls them in-process. `channels` reports each channel's group as `groupId`.

Favorites, favorite order and hidden categories are now stored per Silo profile under `preferences.profiles`. A profile's first save copies the account-wide favorites, and the UI never writes one profile's preferences after an in-app switch to another profile.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests, race tests), plus the JavaScript regression tests for preference sync and per-profile preferences.
