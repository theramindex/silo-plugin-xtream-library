# v0.2.75

Jellyfin channel folders: the `livetv/v1` `channels` route lists, for each channel, the folders the web app files it in. The theramindex Silo fork shows them as a browsable library in Jellyfin clients, next to Live TV. The folders come from a Go port of the web app's folder paths, so both show the same tree for every admin folder setting. Xtream group names stay whole, as in the web app, unless a profile setting splits them; per-user preferences such as splitting groups on `|` are not applied, since the route is the same for every user.

Built against Silo plugin SDK 0.23.0.

Validation: release verification script (vet, full Go tests, race tests), plus the JavaScript regression tests.
