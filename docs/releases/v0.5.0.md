# XC for Silo 0.5.0

Enable Sports-first player and open a matched game from Sports to use the new
game companion: a compact score overlay, player box scores, team statistics,
and play-by-play. Filter player rows by team and set a profile-specific stats
delay from 0 to 300 seconds to suit a delayed feed. Fresh results stay hidden
until the local delay buffer matures, and score-hiding preferences still apply.

Companion requests use the active Silo account and profile. Stopping playback
aborts polling immediately, and responses from an older player or game cannot
publish into the new session. A new game starts with fresh buffer/error state.

Verification includes Go route fixtures, race tests, authenticated lifecycle
regressions, and a Chromium component test for tabs, filters, delayed scores,
mobile layout, and cleanup. Upstream live-data availability still varies by sport.
